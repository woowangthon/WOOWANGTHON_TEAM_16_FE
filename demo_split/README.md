# 시연 영상용 분할 화면

노트북 화면 왼쪽에 실시간 사이트, 오른쪽에 휴대폰 카메라를 나란히 띄우고, 그 화면을 그대로 녹화해요.

## 처음 받았을 때 (한 번만)
휴대폰 카메라는 https로만 열려서 인증서가 필요해요. 인증서와 열쇠는 저장소에 올리지 않으니, 이 폴더에서 한 번 만들어 주세요(Git Bash).

```bash
mkdir -p cert && openssl req -x509 -newkey rsa:2048 -nodes -days 365 -keyout cert/key.pem -out cert/cert.pem -subj "/CN=watchmate-demo" -addext "subjectAltName=DNS:localhost,IP:127.0.0.1"
```

- 파이썬 3.11 이상이면 따로 설치할 것은 없어요. 판정 서버(`watchmate-be`)가 `C:\wm\watchmate-be`가 아닌 곳에 있으면 환경 변수 `WATCHMATE_BE`에 그 폴더를 적어 주세요.

## 켜는 순서
1. 판정 서버(8000)와 화면 서버(5173)를 평소처럼 켜요.
2. `start-demo.bat`을 두 번 눌러요. 크롬에 분할 화면(`http://localhost:8790`)이 열려요.
3. 분할 화면 아래 1번 **연결 방법 보기**의 QR을 휴대폰으로 찍어요.
   - '안전하지 않음' 경고가 나오면 넘어가요(안드로이드: 고급 → 계속, 아이폰: 세부사항 보기 → 이 웹사이트 방문).
   - **카메라 시작**을 누르고 카메라를 허용하면 오른쪽에 영상이 떠요.
4. 3번 **녹화 시작**을 누르고 '이 탭 공유'를 허용해요. 끝낼 때는 화면 맨 위 **공유 중지**를 누르면 영상이 다운로드 폴더에 저장돼요.

## 왼쪽 화면
- **시연 화면(기본):** 평면도에서 구역 색이 바뀌고(변화 없음·변화 가능·변화 큼), 아래에 구역별 신호 변화가 보여요. 판정 서버(8000)의 감지 상태를 1초마다 읽어요.
- **사이트 그대로:** 아래 2번에서 '왼쪽 → 사이트 그대로'를 고르면 실험 사이트가 그대로 떠요.
- **기록 재생(예시):** 2번에서 '판정 → 기록 재생'을 고르면 가장 최근 측정을 8배속으로 다시 보여 줘요. 실제 촬영 때는 '실시간'으로 두세요.
- **실제 상황 표시:** 녹화 도우미(record_live)로 장면을 찍는 중이면 지금 장면이 평면도 위에 떠요. 끄려면 2번의 체크를 빼세요.

## 3D 평면도와 되돌리기
- 시연 화면의 평면도는 기본이 3D예요(방이 입체로 서 있고, 송신 보드에서 전파가 퍼지고, 사람이 감지된 방에 사람 모양과 빛이 떠요).
- 이전 화면으로 돌아가려면 아래 2번에서 **평면도 2D**를 고르면 돼요. 고른 값은 기억돼요.
- 3D 도구(three.js)는 인터넷에서 받아요. 인터넷이 없으면 저절로 2D로 보여요.
- 크게 바꿀 때마다 `versions/` 폴더에 그때의 파일을 복사해 둬요. 되돌리려면 그 폴더의 파일을 위로 덮어쓰면 돼요.

## 장소 바꾸기(site.json)
- 지금은 **S4-1동 1층 106호·107호·복도**로 보여요. 방 이름, 방 크기, 보드 자리는 `site.json` 한 파일에 있어요.
- 단위는 미터예요. x는 106호 서쪽 벽에서 동쪽으로, y는 복도 남쪽 벽에서 북쪽으로 잰 거리예요.
- 지금 숫자는 대피도 사진을 102호 실측(12.15 × 7.0m)에 맞춰 환산한 어림값이에요. 현장에서 재면 숫자만 고치면 되고, 실시간 화면은 몇 초 안에 저절로 바뀌어요(기록 재생은 서버를 다시 켜야 해요).
- `RX-301`이 있는 방이 106호, `RX-302`가 있는 방이 107호예요. 보드를 반대로 두면 `zones`의 이름과 네모를 서로 바꾸면 돼요.
- `site.json`을 지우거나 이름을 바꾸면 원래 2층(223·224호) 도면으로 돌아가요. 판정 서버에 등록된 공간은 건드리지 않아요.
- 기록 재생은 2층에서 잰 기록을 1층 이름으로 보여 주는 거라, 예시로만 보세요.

## 자유 시연
- 단계 안내 없이 자유롭게 움직이면서 찍어요. 화면의 '사람 있음·감지 안 됨'은 들어오는 신호로만 판단해요.
- 단계 안내가 들어 있던 버전은 `versions/2026-11-13_3d_with_steps`에 남겨 뒀어요.

## 휴대폰에서 판정 도면 보기
- 휴대폰 카메라 페이지에 '실시간 판정' 도면이 같이 떠요(노트북 시연 화면과 같은 판정, 1초마다 갱신). 찍는 사람이 방 상태를 보면서 찍을 수 있어요.
- 카메라를 시작하지 않아도 보여요. 그래서 다른 휴대폰으로 같은 QR을 열면 보기 전용으로 쓸 수 있어요.

## 표현과 녹화
- 2번에서 표현을 '사람 있음·감지 안 됨'과 '변화 큼·없음' 중에 고를 수 있어요. 판정은 빈 방 대비 신호 변화라서, 물건을 옮겨도 '사람 있음'으로 떠요.
- 제출한 시연 영상은 문구를 바꾸기 전에 찍어서 '비어 있음', '모든 구역이 비어 있어요'로 보여요. 가만히 누운 사람은 놓칠 수 있어서, 사람이 없다고 읽히지 않게 '감지 안 됨', '지금 감지된 사람이 없어요'로 바꿨어요. 판정 계산은 그대로예요.
- 녹화는 초당 60프레임으로 요청해요(실제 값은 녹화 중 상태 줄에 나와요). 휴대폰 영상은 초당 30장까지예요.

## 녹화 파일이 뒤로 안 넘어갈 때
- 크롬 탭 녹화 파일은 전체 길이 정보가 없어서, 미디어 플레이어에서 길이가 안 보이고 원하는 시각으로 못 넘겨요. 렌더링 중인 게 아니에요.
- `fix-video.bat`을 두 번 누르면 다운로드 폴더의 가장 최근 `watchmate_demo_*.mp4`를 넘길 수 있는 파일(`..._seek.mp4`)로 바꿔 줘요. 다른 파일은 bat 위로 끌어다 놓으면 돼요.
- 화질은 그대로예요(다시 압축하지 않아요). 원본은 지우지 않아요. 230MB 파일이 몇 초면 끝나요.

## 휴대폰이 안 열릴 때
- 휴대폰과 노트북이 같은 와이파이인지 먼저 보세요. 와이파이를 바꾸면 노트북 주소가 바뀌어서 QR도 저절로 바뀌니, QR을 다시 찍어야 해요.
- 서버 창에 휴대폰이 어디까지 왔는지 한 줄씩 나와요('카메라 페이지를 열었어요', '보안 경고 화면에서 멈췄어요', '영상이 들어오기 시작했어요'). 아무 줄도 없으면 휴대폰이 노트북에 닿지 못한 거예요.

## 측정과 같이 쓸 때
- 휴대폰은 **빈 방 보정 전에** 세워 두고 끝까지 건드리지 마세요. 중간에 옮기면 물건을 옮긴 것처럼 '변화'로 잡혀요.
- 휴대폰 와이파이는 5GHz로 붙이세요. 보드가 2.4GHz를 써서 영상 전송이 신호에 섞일 수 있어요.
- 휴대폰과 노트북은 같은 와이파이여야 해요. 학교 와이파이에서 연결이 안 되면 휴대폰 핫스팟(5GHz)에 노트북을 붙이세요.

## 알아 둘 점
- 영상은 초당 10~20장이고 소리는 없어요.
- 와이파이 쪽으로 열리는 것은 카메라 페이지와 사진 올리기뿐이고, 켤 때마다 새로 만드는 열쇠(주소의 `k=`)가 있어야 해요.
- 분할 화면과 영상 보기는 이 노트북 안에서만 열려요.
- `--demo-feed`를 붙여 켜면 휴대폰 연결 전에 시험 영상이 보여요(실제 촬영 때는 붙이지 않아요).
- `cert/`의 인증서는 이 도구 전용이에요. 노트북 주소가 바뀌어도 경고만 넘기면 그대로 쓸 수 있어요.
